# 走在前 开新局|青大附院“同心战疫 青春担当”项目荣获第四届山东省青年志愿服务项目大赛银奖

> 更新时间：2026-09-17 (UTC+8)

//  

近日，以“青春志愿行 建功新时代”为主题的第四届山东省青年志愿服务项目大赛收官，我院“同心战疫 青春担当”青年志愿服务项目荣获银奖。

  //  

此次决赛采用线上方式进行，大赛组委会邀请9名全国及省内志愿服务领域专家担任评委，采取“材料审阅+路演答辩”的方式，对入围项目的可行性、创新性、影响力等进行综合评审。“同心战疫 青春担当”项目，为院团委彩虹志愿方队负责的志愿服务项目，围绕科普宣教、门诊导诊、线上义诊、抗疫宣讲等方面开展疫情防控工作，旨在凝聚青年力量，抗击疫情，护佑生命。

  //  

青岛大学附属医院彩虹志愿方队成立于2013年，由团委直接管理,带领志愿者在卫生健康、应急救援、关爱困境青少年、助老助残、大型赛会服务、疫情防控和改善群众就医体验等领域开展了大量的卓有成效的志愿服务活动。彩虹志愿方队开展的多项志愿服务项目荣获山东省第二届青年志愿服务项目大赛银奖、山东省第三届青年志愿服务项目大赛银奖、第五届中国青年志愿服务项目大赛铜奖、全国卫生健康行业青年志愿服务项目大赛银奖，彩虹志愿方队荣获山东省青年志愿服务先进集体、青岛市卫生健康系统优秀志愿服务组织，多位志愿者获得市级及以上优秀志愿者荣誉称号。

  //  

青大附院青年志愿者将传承百廿年优良传统，始终坚持人民至上、生命至上的理念，不断开创志愿服务发展新局面，让青春在实现中华民族伟大复兴的中国梦中绽放异彩。
