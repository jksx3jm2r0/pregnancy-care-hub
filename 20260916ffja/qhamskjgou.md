# 周期内快速就诊策略

> 更新时间：2026-09-16 (UTC+8)

PART  01：什么是周期

是指夫妻双方经过一系列检查、建好病历档案后，即进入周期。我们常说的周期包括：“试管婴儿新鲜周期”、“人工授精周期”、“冷冻移植周期“等。

PART  02：周期就诊流程

挂号 → 抽血 →B超检查 → 候诊 → 按号看诊 → 开单室录入报告/开单 → 缴费 → 护士站预约手术 → 药房取药 → 注射 

**备注：**

**取号方式：**自助机或手机在线取号

**取号时段：**就诊时段前半小时方可取号。

**缴费方式**：1）微信扫描单子的左上角二维码，手机自助缴费；2）自助机缴费；3）人工收费：生殖科收费窗口、门诊二楼收费窗口；

**女科门诊医生诊室**：急诊楼4楼

**男科门诊医生诊室**：急诊楼5楼

**取药药房**：门诊二楼中西药房

**注射地点**：急诊楼五楼生殖医学中心注射室

**抽血（性激素）地点**：急诊楼五楼生殖医学中心注射室

**B超检查地点**：急诊楼五楼生殖医学中心彩超室

PART  03：周期B超、抽血检查

**周期B超检查**
周期内B超一般主诊医生会亲自做，早上8点之前或按约定时间将B超检查单放在助理桌子上，然后等待助理叫到名字，前往检查。医生自己做的B超没有检查报告，如果B超当天主诊医生不上班，或者是周末时间，则需要去B超室检查，检查完10-20分钟自助打印结果。

阴道B超检查不需要憋尿，反而需要将膀胱里的尿液排出，因此在检查前需要先去卫生间排空小便。

**抽血检查****性激素**抽血时间安排

周一至周五（正常工作日）：07:30-08:25

周末及节假日：08:00-08:25

08:25之前在急诊楼五楼生殖医学中心注射室抽血， 08:25以后请到门诊楼三楼操作区抽血
**日常激素抽血注意要点**

☑ 刚到医院应休息10分钟再抽血，以免影响血液检查结果。严禁奔跑、情绪激动！建议在安静状态下抽血。（泌乳素项目的最佳抽血时间为09:00---11:00）。

☑ 超过生殖医学中心抽血时间请到门诊楼三楼操作区抽血，最迟不得超过09:00，否则抽血报告下午才能出来，影响用药时间。

☑ FSH 、E2、LH、P抽血项目当天可以进食早餐、饮水，穿宽口衣袖的衣服，以免袖口太紧导致抽血后针眼出血不止。抽血后请按压针眼处5分钟。

☑  性激素六项抽血应在月经期2-5天内检查。

**周期内B超、抽血检查的意义**
**★ ****抽血查性激素：**主要监测激素水平的变化（包括卵泡刺激素、雌激素、黄体生成素、孕酮水平）；医生会根据激素水平、卵泡发育状况调整用药；

**★**** 阴道B超检查：**主要是观察卵泡生长的个数和速度以及内膜发育情况，以此来调整促排卵药物的用量。

PART  04：注射促排药物
******请您每天尽可能在相对固定的时间注射，上下波动两个小时亦无大碍。您可以选择就近社康中心或方便的正规医院注射；****促排卵期间请不要剧烈运动，突然改变体位或憋尿。****促排期间饮食上可多吃高蛋白食物。
****切记：注射药物不能冷冻或室温保存哦！**
**路途遥远者可用“保温袋+冰袋**”携带**（尤其是夏季，避免室外温度高而导致药物失效）**，促卵泡药物回家后放于冰箱水果蔬菜栏冷藏保存（2-8°）。
