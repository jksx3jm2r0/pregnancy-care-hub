# 皮皮虾营养价值相当高 别信孕妇吃了会流产的谣言

> 更新时间：2026-09-11 (UTC+8)

皮皮虾的爆火是因为前几年的一句网络语：皮皮虾我们走！于是皮皮虾正式进入大众的视野，就连小孩也知道。那么孕妇是否可以吃皮皮虾呢？有一种说法是孕妇吃了皮皮虾会流产，其实事实并不是这样的，相反，皮皮虾对孕妇还有很多好处。

皮皮虾我们走

孕初期孕妇能吃皮皮虾吗

不管是怀孕早中晚期，孕妇都是可以吃皮皮虾的，也并不会导致孕妇流产。皮皮虾又叫口虾蛄，全为海，分布范围极广，孕期吃皮皮虾不仅对胎儿没有坏的影响，还有许多好处。

孕妇吃皮皮虾的好处

1、对准妈妈的好处

皮皮虾肉质鲜嫩多汁，是一种美味的海鲜，能增进准妈妈的食欲，亦能补充钙质和多种微量元素，孕妇食用皮皮虾，能补充镁元素，能很好的保护心血管系统，有利于调节好心脏活动，同时可减少血液中胆固醇含量，防止动脉硬化，能扩张冠状动脉，有利于预防高血压及心肌梗死，而且虾的通乳作用较强。

发亮、发青的虾是新鲜的

2、对胎儿的好处

皮皮虾中还含有丰富的钙质，不但可以促进胎宝宝骨骼的长，还可以促进宝宝们脑部的发育。

孕妇吃皮皮虾的注意事项与禁忌

- 
过敏者勿食

- 
吃皮皮虾的时候一定不能同时吃大量维素C

- 
皮皮虾不宜与猪肉同同时食用

- 
皮皮虾不可以与狗肉、鸡肉、獐肉、鹿肉、南瓜同食

- 
喝果汁的同时是不能吃皮皮虾，否则会导致腹泻

- 
不宜与柿子、山楂、石榴、葡萄等同吃

- 
食用前要洗干净

适于孕妇的皮皮虾食谱

1、椒盐皮皮虾

食材：皮皮虾、蒜头、干红椒、料酒、盐、椒盐

做法

将虾用清水反复冲洗干净，淋入料酒和少许盐搅拌均匀

大蒜去皮切碎末，干红椒切小段

锅中倒入油，大火加热至6成热（油温过高会直接糊了），将虾放入中火炸至虾身变成红色，捞出沥油

倒出锅中多余的油留少许底油，放入蒜末和红椒，小火慢慢煸香

将虾倒入锅中，撒入椒盐翻炒几下即可食用

2、酱炒皮皮虾

食材：皮皮虾、甜面酱适量、葱适量、姜适量、蒜适量、干辣椒适量、食盐适量、白酒适量、色拉油适量

做法

把虾放入盆中，用清水清洗干净，葱姜蒜切末，辣椒切碎备用

锅里放2大勺油，油热后，将辣椒和葱姜蒜放入锅中爆香，然后倒入皮皮虾翻炒，加入一小勺的料酒、一小勺的盐

不断翻炒，等皮皮虾颜色变红，加入一大勺的甜酱继续翻炒，直到完全熟透即可食用

3、清炒皮皮虾

食材：皮皮虾、小葱适量、姜适量、蒜适量、红尖椒适量、花椒适量、十三香适量、酱油适量、海鲜酱适量、食盐适量、色拉油适量

做法

皮皮虾洗净备用，葱洗净备用，辣椒洗净备用，姜洗净备用，大蒜备用

将洗净的葱切段，葱叶切碎，姜切片，大蒜切小块，辣椒切宽丝备用

锅中放油，下花椒爆香

下入切好的葱姜蒜和辣椒翻炒，同时放入少许盐和十三香

将皮皮虾倒入锅内翻炒，加入少许味极鲜，放入海鲜酱

翻炒均匀，入味即可关火，装盘上桌食用

准妈妈们也不能放开了吃

4、白灼皮皮虾

食材：皮皮虾，盐适量、姜适量、葱适量

做法

将皮皮虾洗干净，沥干水分

姜切片，葱留葱白切长段

锅烧适量清水放入姜、葱白

待水开放入洗净的皮皮虾

放入适量的盐

待水开盖上锅盖煮5分钟

皮皮虾熟透即可起锅食用

除此之外，皮皮虾还有许多做法。皮皮虾属于寒凉性食物，孕妇不要吃太多，食用时最好和姜醋等调料一起食用，降低其寒性还能杀菌。
